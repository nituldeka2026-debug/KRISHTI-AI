# KRISHTI AI V16.0

## Render deployment fix
- Node is pinned to `22.x` in `package.json`.
- The stale/broken `package-lock.json` is intentionally removed; Render will generate a fresh lockfile during `npm install`.
- In Render, use **Manual Deploy → Clear build cache & deploy** after pushing this version.

## V16 server routes
- `/api/chat` — AI chat
- `/api/search` — Gemini Google Search grounding
- `/api/image-edit` — image editing
- `/api/image-generate` — text-to-image / past / future image generation
- `/api/activity` — usage activity
- `/api/settings` — settings persistence
- `/api/admin/stats` — admin analytics

## Required environment
Keep Gemini and Firebase secrets on the server. Do not put API keys in frontend files.
