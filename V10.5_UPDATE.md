# Krishti AI V10.5 — ChatGPT-style layout update

## UI changes
- Responsive ChatGPT-inspired sidebar with New Chat, recents, tools and Settings.
- Mobile sidebar drawer with overlay, hamburger menu and New Chat action.
- Cleaner top bar with Krishti AI avatar, online status, rename and new-chat controls.
- Removed the visible large document-upload card from the main chat area.
- Added compact `+` attachment menu: Camera, Photos, Files, Plugins and Think harder.
- Image attachment shows an inline preview with remove control.
- Document attachment shows filename, type/size and remove control above the composer.
- Composer is centered and fixed near the bottom on mobile/desktop, with voice and send controls.
- Existing authentication, chat history, document API and image-edit API code preserved.

## Run
```bash
npm install
npm start
```
