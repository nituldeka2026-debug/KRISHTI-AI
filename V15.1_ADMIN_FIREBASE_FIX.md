# Krishti AI V15.1 — Firebase Admin + Real User Count Fix

- Render Secret File support added.
- Default secret filename: `firebase-service-account.json`.
- The server reads `/etc/secrets/firebase-service-account.json` automatically.
- Admin stats now read the real Firebase Authentication user list using Firebase Admin SDK `listUsers()` and merge local activity counters.
- Admin account remains `nitul.deka2026@gmail.com` by default.
- No service-account key is included in this ZIP.

## Render
1. Environment → Secret Files → `firebase-service-account.json`.
2. Paste the full Firebase service-account JSON.
3. Save changes and let Render redeploy.
4. Reload Krishti AI and open Admin Dashboard.
