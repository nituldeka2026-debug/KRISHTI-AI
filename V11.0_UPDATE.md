# Krishti AI V11.0

## New
- Added a real Web Search mode in the + attachment menu.
- Web Search uses Gemini's Google Search grounding tool on the server.
- Search results can include a Sources section with URLs returned by grounding.
- Added a visible Web Search mode indicator and search-specific composer placeholder.
- Search mode automatically turns off after each request.

## Preserved
- Krishti custom branding and official logo.
- Firebase authentication.
- Local per-user chat history and Recents.
- Document upload and document-aware chat.
- Image upload and Gemini image editing.
- ChatGPT-inspired sidebar/settings layout, customized for Krishti AI.
