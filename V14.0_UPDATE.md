# Krishti AI V14 — Settings 2.0

This release replaces the old ChatGPT-like settings list with a Krishti-native Control Center. Every main setting now has a frontend control and a backend persistence path.

## Backend
- `GET /api/settings?user=...` loads the user's settings.
- `PUT /api/settings` saves the settings object.
- `POST /api/feedback` stores bug reports.
- Settings are stored server-side in `data/settings.json`, keyed by a SHA-256 hash of the supplied Firebase UID/email.
- This is a lightweight app-level persistence layer. Production deployments should add Firebase Admin ID-token verification before treating the backend key as authenticated authorization.

## Functional settings
- Krishti Profile
- Krishti Personality + custom instructions
- My Preferences
- Krishti Memory / Conversation Recall / Knowledge
- Krishti Look / Colors / Chat Experience / Voice & Sound
- Web Explorer / Vision & Images / Document Brain / Connected Tools
- Privacy / Memory Control / Security / Data & Storage / Safety
- Mobile Experience / Notifications / Offline & Network / App Updates
- What's New / Labs / Help / Bug reports / About / Log out

## Chat integration
Personality, custom instructions, language, response length and memory preference are added to the chat request sent to `/api/chat`.

## Important
The app's chat history and Library remain browser-local in this build. The new settings backend is real persistence, but it is not a full cloud database or Firebase-admin authorization system.
